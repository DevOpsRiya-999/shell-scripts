## 🚀 Quick Start

### Prerequisites
Ensure you are running a Unix-like environment (Linux, macOS, or WSL on Windows) with `bash` version 4.0+. 

Some scripts require the following packages installed:
* `curl`
* `jq` (for parsing JSON data)

### Make Scripts Executable
Before running any script for the first time, you must give it execution permissions:
```bash
chmod +x scripts/*.sh
```
